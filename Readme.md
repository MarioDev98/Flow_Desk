# Flow Desk

**Flow Desk** is a task management system designed to organize, track, and monitor daily activities through a simple and intuitive web interface.

The system allows users to create and manage tasks through different workflow states, while also providing productivity metrics and a task history.

---

## Features

### Task Management

Users can create and manage tasks using the following workflow states:

- **New** – Task has been created but work has not started.
- **In Progress** – Task is currently being worked on.
- **Dependency** – Task is waiting for an external dependency or action.
- **Completed** – Task has been successfully completed.

### Productivity Dashboard

The system includes a productivity panel where users can review productivity-related information and task performance.

To access the **Productivity** section:

> Click or tap the card labeled **"AUTOR"**.

### Task History

The system also provides a history of tasks and their activity.

To access the **History** section:

> Click or tap the card labeled **"TOTAL"**.
